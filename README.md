# D&D / TaleSpire Market Bot v3

В этой версии исправлена кнопка «Объявления» и добавлена простая web-панель администратора.

## Что изменилось в боте

- `📋 Объявления` теперь имеет отдельный обработчик и открывает общий список товаров.
- `💰 Пополнить баланс` есть в главном меню и в профиле.
- В карточке товара две кнопки оплаты:
  - `⭐ Оплатить Stars` — текущая Telegram Stars оплата.
  - `💳 СБП / Карта` — пока показывает уведомление, что оплата ещё не подключена.
- Записываются действия пользователя.
- Записываются просмотры карточек товаров.
- Пополнения и покупки сохраняются в истории.
- Тикеты имеют историю переписки.
- Ответ поддержки можно отправлять пользователю из web-панели.
- Обычные пользователи остаются анонимными в публичном разделе.
- Стартовые товары администрации остаются `✅ проверенными`.

## Web-панель

Запускается вместе с ботом по адресу:

`http://127.0.0.1:8080`

В панели есть:

### 🆘 Тикеты

- список всех тикетов;
- открытые/закрытые;
- просмотр всей переписки;
- ответ пользователю прямо из сайта;
- закрытие тикета;
- удаление тикета.

Ответ с сайта отправляется пользователю в Telegram через бота.

### 👥 Пользователи

Для каждого пользователя:

- Telegram ID;
- username;
- роль;
- баланс;
- репутация;
- время последней активности;
- все записанные действия;
- какие товары открывал;
- история пополнений;
- история покупок;
- ручное изменение баланса.

### 📦 Товары

Просмотр всех товаров, продавцов, цен, статуса и отметки проверки.

## Запуск

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `ADMIN_IDS`, `ADMIN_WEB_USER`, `ADMIN_WEB_PASSWORD`.

Затем:

```bash
python run.py
```

Бот работает как раньше, а web-панель — на порту 8080.

Для доступа извне не рекомендуется просто открывать 8080 в интернет. Лучше использовать HTTPS + reverse proxy/VPN.

## Миграция

Если есть старый `market.db`, новая версия сама создаёт недостающие таблицы и поле `last_seen_at`.

Сделайте резервную копию БД перед обновлением.

## Оплата СБП / картой

Кнопка уже встроена в карточки товаров, но реальный эквайринг намеренно не подключён: сейчас она сообщает пользователю, что функция находится в разработке. Подключение конкретного эквайринга можно сделать отдельным модулем после выбора провайдера и юрсхемы магазина.
